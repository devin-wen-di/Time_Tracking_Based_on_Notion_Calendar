# Notion 时间使用分析

这是一个 Windows 一键运行的 Notion 日程同步与分析工具。日常数据以 CSV 为唯一导出和分析输入格式；程序运行不需要安装 Python。

## 一键使用

双击 `Notion时间分析.lnk` 或 `start_app.bat`。程序会只读同步 Notion `Parent databases` 下的数据库，将每个数据库覆盖导出为独立 CSV，然后启动本机网页并自动载入这些 CSV。关闭启动窗口会停止本机网页。

如果 Notion 同步失败，程序保留上次成功的 CSV 并在页面显示失败原因。第一次同步需要先配置 `NOTION_API_KEY`，并将目标页面和数据库共享给 Notion integration。密钥只由本机程序使用，不会传给网页。

## CSV 字段

每个数据库 CSV 含有 `Event`、`Event Date Start`、`Event Date End`、`Time allotted`、`Select`、`WK #`、`Year`、源数据库名称、数据源名称、Notion 页面 ID、源记录链接，以及其它数据库属性列。UTF-8 with BOM 编码，适合表格软件打开。`manifest.csv` 记录导出清单，`sync_status.csv` 记录同步状态；程序不再导出数据库 JSON 文件。

## 计算规则

- 每个 CSV 对应的 Notion 数据库作为一个类别。
- 优先读取 `Time allotted` 的有效数值；缺失时用开始和结束时间补算。两种时长相差超过一分钟会标异常。
- 有有效时长但日期缺失的记录计入总时长和类别汇总，不进入趋势图。日期与时长都缺失的记录保留并提示。
- 时间趋势按日显示；已有的 `WK #` 和年份保留在活动明细中。摘要将有日期的活动与上一等长周期比较，日期缺失的活动不用于周期比较。
- 重叠记录会标记，但不删除、不扣减；未记录时长按选定日期范围内未被活动时间覆盖的时间估算。
- 小时保留两位小数，占比保留一位小数。筛选会同步作用于指标、图表和明细。

## 网页交互

- 日期范围提供默认、今天、昨天、近 3 天、近 7 天、近 30 天和自定义时间。
- 默认视图显示昨天、近 3 天、近 7 天三层环形类别图，默认高亮昨天；点击任一环可切换高亮范围和下方时长/占比列表。近 3 天和近 7 天列表还显示日均时长。
- 页面右上角可切换深色或浅色模式。点击“时间分配”可选择类别、设置颜色与每日目标并拖动排序；“显示时间分配”会在占比图外侧显示目标环。勾选类别的目标合计不能超过 24 小时，剩余时间归为其他。主题、类别颜色与时间分配都保存在 `dashboard_settings.csv`，下次打开仍会沿用。时间趋势从全部历史记录中取数，图窗一次显示连续 14 天；左右按钮让图窗每天向前或向后移动一天。趋势按类别堆叠显示，并使用与类别占比相同的颜色；点击柱状色块可查看对应日期与类别的活动明细。
- 日程与可安排时间可按天查看所有类别的已同步活动，并显示当天未来或未来日期 08:00–22:00 内至少 30 分钟的空档；当活动缺少有效结束时间时不推测空档。新建或修改日程仍在 Notion 中进行，重新启动工具后同步。
- 未记录时长依据全部类别的实际起止区间计算；类别筛选不会把其他类别的活动误判为未记录。趋势窗口和日程规划独立于上方日期范围，活动明细与汇总遵循上方筛选。
- 时间重叠和无有效时长提示显示在活动明细下方。

## 定时同步

`run_export.bat` 仅执行 API 同步并退出，可用 Windows 任务计划程序按需定时运行。之后重新打开快捷方式会自动读取最新 CSV。`install_daily_schedule.ps1` 可用于创建每日计划任务。

## 源码与单文件程序

`notion_calendar_export.py` 是导出和本机网页服务源码，`time_dashboard.html` 是分析界面，`notion_calendar_app_v2.exe` 是无需 Python 的 Windows 程序。`exports/latest` 保存最近成功导出的 CSV。





## 阿里云每周邮件周报

可将 `alibaba_fc_weekly_report` 部署到阿里云函数计算，定时只读 Notion 并向指定邮箱发送类别占比和每日趋势图。部署步骤、环境变量和计算口径见该目录的 README；运行 `package.ps1` 可生成供函数计算上传的 ZIP。密钥需在阿里云函数配置中录入。
